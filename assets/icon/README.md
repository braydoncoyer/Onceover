# Icon

The Onceover app icon: the corner of a diff file panel on a dark tile, fading to dark at the bottom the way long diffs do in the app.

- `onceover-icon.svg`: the 1024 master. `onceover-icon-32.svg` and `onceover-icon-16.svg` are hand-tuned cuts for small sizes.
- `onceover-1024.png`, `onceover-256.png`: renders of the master.
- `Onceover.icns`, `Onceover.iconset/`: macOS app icon set.
- The favicon and Apple touch icon the UI serves live in `ui/icon/`.

The source is a Claude Design canvas; these files are exported from it.
